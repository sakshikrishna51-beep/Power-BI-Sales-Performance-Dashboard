# Power BI Sales Performance Dashboard

## Project Overview
This project is an interactive Power BI dashboard designed to analyze sales and profit performance across categories, regions, and time. The dashboard enables business users to monitor KPIs, identify trends, and evaluate regional performance using dynamic filters.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Data Modeling
- Power Query

## Dashboard Features
- KPI cards for Total Sales and Total Profit
- Monthly sales trend analysis
- Sales and profit comparison by category
- Regional performance breakdown
- Interactive slicers for Year, Region, and Category
- Dedicated filters page for focused analysis

## Key Business Insights
- Technology category contributes the highest profit
- Sales show a consistent upward trend over time
- Western and Eastern regions outperform others in revenue
- Filter-based exploration enables quick decision-making
